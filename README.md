## Documentation
* Includes Facebook Opengraph metatags in header, with a selection of pictures to display in a link from Facebook. 
* Also makes it possible to incude a custom script in the head.

## Upgrade Notice    
* from 2024 (v2.1.0) requires Joomla 4, php 7.4.
